# NIT Trichy campus places (CampusRide knowledge base)

Use only these place names for pickups and drops. Each line lists other words people use for the same place.

- **Main Gate**: front gate, gate, entrance, मेन गेट, மெயின் கேட். The campus entrance on the main road.
- **Admin Building**: admin block, administration, office, एडमिन, அட்மின். Near the Main Gate.
- **Central Library**: library, lib, लाइब्रेरी, पुस्तकालय, லைப்ரரி, நூலகம்.
- **Octagon**: computer centre, computer center, ऑक्टागन, ஆக்டகன்.
- **Hospital**: health centre, medical, dispensary, clinic, हॉस्पिटल, अस्पताल, மருத்துவமனை. For medical emergencies.
- **Orion**: Orion building, new academic block, ओरियन, ஓரியன்.
- **Lecture Hall Complex**: LHC, lecture hall, classes, एलएचसी, லெக்சர் ஹால்.
- **Barn Hall**: Barn, auditorium, बार्न हॉल, பார்ன் ஹால்.
- **Diamond Hostel**: Diamond, डायमंड, டயமண்ட்.
- **SAC**: Student Activity Centre, club rooms, एसएसी.
- **Mega Mess**: mess, canteen, food, dining, मेगा मेस, मेस, மெஸ்.
- **Sports Complex**: sports, ground, stadium, gym, स्पोर्ट्स, ग्राउंड, மைதானம்.
- **Opal Hostel**: Opal, girls hostel, ओपल, ஓபல்.
- **Agate Hostel**: Agate, अगेट, அகேட்.
- **Garnet Hostel**: Garnet, गार्नेट, கார்னெட்.
- **Zircon Hostel**: Zircon, ज़िरकॉन, ஜிர்கான்.

Service: campus EVs run only between these places, inside the campus. There is no fare for campus rides (demo assumption).
